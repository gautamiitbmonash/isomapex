🌍 OSM Multi-Mode 3D Route Explorer

Click multiple points on the OpenStreetMap map to create a route. Each section between two points can use a different transportation mode. The resulting route, buildings and transport infrastructure are displayed in an interactive isometric 3D view.
Click the map repeatedly to add Point 1, Point 2, Point 3, etc. Drag markers to reposition them.

🚌 Public Transport
Public transport: the public OSRM server used by this standalone example does not calculate bus/metro/train itineraries. Transit segments are therefore shown in blue but use a walking route geometry as a visualization fallback. Replace the transit routing function with OpenTripPlanner or another GTFS/transit API for real transit routing.
